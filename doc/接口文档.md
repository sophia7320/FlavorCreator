# 创味机 Flavor Creator - API 接口文档

> 微信小程序版本

## 一、接口规范

### 1.1 基础信息
- **协议**: HTTP/HTTPS
- **数据格式**: `application/json`
- **字符编码**: UTF-8
- **时间格式**: ISO 8601 (`YYYY-MM-DDTHH:mm:ssZ`)

### 1.2 响应格式
```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

### 1.3 错误码
| 错误码 | 说明 |
|--------|------|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未登录/Token 过期 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |
| 1001 | 微信 code 无效 |
| 1002 | 微信接口调用失败 |
| 1003 | 手机号获取失败 |
| 2001 | 图片格式不支持 |
| 2002 | 图片大小超出限制 |
| 2003 | 图片包含违规内容 |
| 2004 | 图片审核服务异常 |

## 二、微信登录模块

### 2.1 微信一键登录（核心接口）
```
POST /api/auth/login-wx
```

**请求参数**:
```json
{
  "code": "微信登录码，通过 wx.login() 获取",
  "userInfo": {
    "nickName": "用户昵称",
    "avatarUrl": "用户头像",
    "gender": 1
  }
}
```

**响应**:
```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "refreshToken": "refresh_xxxx...",
    "expiresIn": 7200,
    "needBindPhone": false,
    "user": {
      "id": 10001,
      "nickname": "用户昵称",
      "avatar": "https://...",
      "phone": "138****0000",
      "isNewUser": false
    }
  }
}
```

**后端处理逻辑**:
1. 使用 `code` 调用微信 `auth.code2Session` 接口获取 `openid` 和 `session_key`
2. 判断用户是否已注册（根据 openid 查询）
3. 已注册：生成 token 返回用户信息
4. 未注册：自动创建用户并返回 `isNewUser: true`

---

### 2.2 刷新 Token
```
POST /api/auth/refresh
```

**请求参数**:
```json
{
  "refreshToken": "刷新令牌"
}
```

**响应**:
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "token": "新的访问令牌",
    "refreshToken": "新的刷新令牌",
    "expiresIn": 7200
  }
}
```

---

### 2.3 微信登录 - 后端与微信接口交互

后端需要调用微信官方接口：

| 接口 | 说明 |
|------|------|
| `https://api.weixin.qq.com/sns/jscode2session` | code2Session 获取 openid 和 session_key |

**code2Session 请求示例**:
```
GET https://api.weixin.qq.com/sns/jscode2session?appid=APPID&secret=SECRET&js_code=CODE&grant_type=authorization_code
```

**响应**:
```json
{
  "openid": "oXXXX_openid",
  "session_key": "xxxx_session_key",
  "unionid": "oXXXX_unionid"
}
```

---

### 2.4 退出登录

（前端将token置空）

```
POST /api/auth/logout
```

**Headers**: `Authorization: Bearer <token>`

**响应**:

```json
{
  	"code": 200,
    "message": "退出成功",
    "data": null
}
```

## 四、菜谱模块

### 4.1 发布菜谱

```
POST /api/recipe
```

**Headers**: `Authorization: Bearer <token>`

**请求类型**: `multipart/form-data`

**请求参数**:
| 参数 | 类型 | 说明 |
|------|------|------|
| request | JSON | `PublishRecipeRequestDTO`，JSON 部分，字段见下方 |
| cover | file | 封面图片（必传） |
| images | file[] | 步骤图片（可选） |

**request JSON 字段**:
```json
{
  "name": "我的秘制红烧肉",
  "ingredients": "[{\"name\":\"五花肉\",\"quantity\":500,\"unit\":\"克\"}]",
  "steps": "[{\"order\":1,\"description\":\"五花肉切块焯水\"}]",
  "tags": "[\"家常菜\",\"特色菜\"]",
  "category": "home",
  "tips": "小火慢炖更入味",
  "cookTime": 45,
  "difficulty": 2,
  "calories": 580
}
```

**响应**:
```json
{
  "code": 200,
  "message": "success",
  "data": 2001
}
```

> **注意**：图片上传后会经过三步校验（格式→大小→内容审核），审核失败返回 2001~2004 错误码。

## 十一、前端微信小程序调用示例

### 登录流程
```javascript
// 1. 微信登录获取 code
wx.login({
  success: (res) => {
    const code = res.code;
    
    // 2. 调用后端登录接口
    wx.request({
      url: 'https://api.example.com/api/auth/login-wx',
      method: 'POST',
      data: { code, userInfo: { nickName: '', avatarUrl: '', gender: 0 } },
      success: (res) => {
        const { token, user } = res.data.data;
        // 3. 存储 token
        wx.setStorageSync('token', token);
        wx.setStorageSync('userInfo', user);
      }
    });
  }
});
```

### 带 Token 的请求
```javascript
// 封装请求
const request = (options) => {
  const token = wx.getStorageSync('token');
  return wx.request({
    ...options,
    header: {
      ...options.header,
      'Authorization': `Bearer ${token}`
    }
  });
};

// 使用
request({
  url: 'https://api.example.com/api/user/info',
  method: 'GET',
  success: (res) => {
    console.log('用户信息:', res.data.data);
  }
});
```
